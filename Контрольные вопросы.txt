Ответы на контрольные вопросы
1. Что такое адаптивная вёрстка?

Адаптивная вёрстка — это создание сайта, который изменяет расположение и размеры элементов в зависимости от размера экрана устройства.

2. Для чего используются media queries?

Media queries позволяют применять определённые CSS-стили только при выполнении заданного условия.

Например:

@media (max-width: 576px) {
    .container {
        grid-template-columns: 1fr;
    }
}
3. Разница между max-width и min-width?

max-width применяет стили, когда ширина экрана не превышает указанное значение.

@media (max-width: 576px)

min-width применяет стили, когда ширина экрана не меньше указанного значения.

@media (min-width: 768px)
4. Что такое breakpoints?

Breakpoints — это точки изменения дизайна сайта в зависимости от ширины экрана.

Например:

576px — телефон;
768px — планшет;
992px — большой экран.
5. Почему важен meta viewport?

Он позволяет браузеру правильно масштабировать страницу на мобильных устройствах.

<meta name="viewport" content="width=device-width, initial-scale=1.0">
6. Как Grid помогает адаптивности?

Grid позволяет изменять количество колонок в зависимости от ширины экрана.

Например:

grid-template-columns: repeat(3, 1fr);

на компьютере и:

grid-template-columns: 1fr;

на телефоне.

7. Как Flexbox используется в адаптивной вёрстке?

Flexbox позволяет гибко располагать элементы и изменять их направление при уменьшении экрана.

Например:

footer {
    display: flex;
}

а на телефоне:

footer {
    flex-direction: column;
}
8. Можно ли использовать несколько media queries?

Да. На одной странице можно использовать несколько media queries для разных размеров экранов.

В данной работе используются два:

@media (max-width: 768px)

и:

@media (max-width: 576px)
9. Что будет без viewport meta?

На мобильных устройствах страница может отображаться как уменьшенная версия страницы для компьютера, из-за чего текст и элементы будут плохо восприниматься.

10. Разница адаптивного и отзывчивого дизайна?

Адаптивный дизайн использует заранее определённые варианты отображения для разных размеров экрана. Отзывчивый дизайн более гибко изменяет размеры и расположение элементов в зависимости от доступного пространства.
